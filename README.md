FlatCAM is a program for preparing CNC jobs for making PCBs on a CNC router.
Among other things, it can take a Gerber file generated by your favorite PCB
CAD program, and create G-Code for Isolation routing.


# Installation instructions

Works with Python version 3.11 or greater and PyQt6.

More on the YouTube channel: 
https://www.youtube.com/playlist?list=PLVvP2SYRpx-AQgNlfoxw93tXUXon7G94_

## Running from Sources (any operating system)

1. Git clone the project

```bash
git clone https://github.com/VitinLima/flatcam.git
```

2. Create a python virtual environment

```bash
python3 -m venv venv
```

3. Activate the environment

```bash
source venv/bin/activate
```

4. Launch FlatCAM

```bash
python3 flatcam.py
```
